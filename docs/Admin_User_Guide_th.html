ภาพรวมและการเตรียมพร้อม

หน้านี้เป็นตัวอย่าง HTML ของคู่มือ Admin License Tool ซึ่งจัดวางเนื้อหาให้เข้าใจง่าย มีสีและตัวอักษรที่สอดคล้องกัน พร้อมภาพประกอบและขั้นตอนการใช้งานจริงตามระบบที่พัฒนาไว้

ไฟล์รูปถูกอ้างอิงจากโฟลเดอร์: assets/manual/admin/

เคล็ดลับ: คุณสามารถเปิดไฟล์นี้โดยตรงผ่านเบราว์เซอร์ หรือโฮสต์ผ่าน python -m http.server

โครงสร้างหน้าจอหลัก

ส่วนควบคุมคีย์และฟอร์ม

  • เลือกคีย์ส่วนตัว (PEM)
  • กรอกข้อมูลลูกค้าและผลิตภัณฑ์
  • ตั้งค่าโหมดใบอนุญาต: Standard, Offline
  • กำหนดวันหมดอายุและการใช้งานออฟไลน์

ผลลัพธ์และการบันทึก

  • พรีวิว payload และลายเซ็น
  • บันทึกไฟล์ใบอนุญาต .dat
  • ข้อความแจ้งเตือนสถานะการทำงาน

วิธีใช้งานแบบ Step-by-Step

  1. กดปุ่ม “เลือกคีย์ส่วนตัว” แล้วเลือกไฟล์ admin_ed25519_private_key.pem
  2. กรอกข้อมูลลูกค้าและผลิตภัณฑ์ให้ครบถ้วน
  3. เลือกโหมดไลเซนส์: Standard หรือ Offline พร้อมกำหนดวันหมดอายุ
  4. กด “สร้างไลเซนส์” เพื่อให้ระบบเข้ารหัสและเซ็น payload
  5. ตรวจสอบพรีวิว แล้วกด “บันทึกไฟล์ไลเซนส์” เพื่อสร้างไฟล์ license.dat

ตัวอย่างการใช้งาน

โหมด Standard

ลูกค้าต่ออินเทอร์เน็ตเพื่อยืนยันใบอนุญาตเมื่อใช้งานครั้งแรก

โหมด Offline

ลูกค้าสามารถทำงานเสร็จสมบูรณ์โดยไม่เชื่อมต่อเครือข่าย ตามช่วงเวลาที่กำหนด

ภาพประกอบพร้อมคำอธิบาย

ภาพประกอบประกอบด้วยภาพจริงจากหน้าจอ Admin Electron พร้อมคำอธิบายและหมายเลขอ้างอิงให้สอดคล้องกับหัวข้อในคู่มือ

  • รูปที่ 1 – หน้าต่างหลัก (ภาพจริง)
  • รูปที่ 2 – สถานะคีย์ส่วนตัวถูกโหลด (ภาพจริง)
  • รูปที่ 3 – ฟอร์มข้อมูลลูกค้าและผลิตภัณฑ์ (ภาพจริง)
  • รูปที่ 4 – พรีวิวไฟล์ใบอนุญาต (ภาพจริง)
