# คู่มือการใช้งานระบบจัดการสิทธิ์ (License Management)

หน้านี้ถูกออกแบบให้ใช้งานเฉพาะงานจัดการสิทธิ์การใช้งานเท่านั้น โดยไม่มีส่วนแชทปรึกษา AI ปรากฏร่วมอยู่ เพื่อความชัดเจนและลดสิ่งรบกวนในการทำงานของผู้ดูแลระบบสิทธิ์

## เป้าหมายของหน้า License
- แสดงข้อมูลสถานะสิทธิ์การใช้งานของเครื่อง (Hardware ID, สถานะ, วันคงเหลือ, วันหมดอายุ)
- นำเข้าไฟล์สิทธิ์ (`license.dat` หรือ JSON) ไปยังตำแหน่งที่เลือก
- แสดงรายการผู้ใช้งานและสิทธิ์ที่ได้รับ พร้อมฟังก์ชันค้นหาและกรองตามสถานะ

## ส่วนประกอบหลัก

### 1) ข้อมูลสิทธิ์การใช้งาน
- `Hardware ID`: กดปุ่มคัดลอกเพื่อส่งให้ผู้ดูแลออกไฟล์สิทธิ์
- `สถานะสิทธิ์`: แสดง Active/Grace/Expired/Revoked ฯลฯ พร้อมสีสถานะ
- `วันคงเหลือ` และ `ใช้ได้ถึง`: สรุปช่วงระยะเวลาการใช้งานตามไฟล์ที่ตรวจสอบได้
- ปุ่ม `นำเข้าสิทธิ์การใช้งาน` และ `ตรวจสอบสถานะ`: ใช้หลังจากเลือกไฟล์และตำแหน่งติดตั้งแล้ว

### 2) รายการผู้ใช้งานและสิทธิ์
- ช่องค้นหา: พิมพ์ชื่อ/อีเมล/บทบาท เพื่อกรองรายการแบบทันที
- ตัวกรองสถานะ: เลือก `ทั้งหมด`, `ใช้งานได้`, `ช่วงผ่อนผัน`, `หมดอายุ`, `ถูกเพิกถอน`
- ตารางข้อมูล: `ผู้ใช้งาน`, `อีเมล`, `บทบาท`, `ประเภทสิทธิ์`, `สถานะ`, `วันหมดอายุ`

หมายเหตุ: รายการผู้ใช้งานโหลดจาก API `/api/license/users` และจะปรับขนาดหน้าอัตโนมัติให้พอดีกับหน้าจอ โดยไม่มี scrollbar

## ขั้นตอนการใช้งาน
1. เปิดแท็บ `สิทธิ์การใช้งาน` จากเมนูด้านบน
2. ตรวจสอบ `Hardware ID` และ `สถานะสิทธิ์`
3. หากต้องนำเข้าไฟล์สิทธิ์:
   - กด `เลือกไฟล์` เลือก `license.dat` หรือไฟล์ JSON ที่ได้รับ
   - เลือก `ตำแหน่งติดตั้ง` (ผู้ใช้/ระบบ/โฟลเดอร์ปัจจุบัน)
   - กด `นำเข้าสิทธิ์การใช้งาน` แล้วกด `ตรวจสอบสถานะ`
4. ตรวจสอบรายการผู้ใช้งาน:
   - ใช้ช่องค้นหาและตัวกรองเพื่อตรวจสอบผู้ใช้และสิทธิ์ที่ได้รับอย่างชัดเจน

## การทดสอบระบบ
- เปิดหน้า License และตรวจว่าหน้าไม่มีองค์ประกอบแชทปรึกษา AI ปรากฏ
- ทดสอบ `คัดลอก Hardware ID`, `นำเข้าไฟล์สิทธิ์`, `ตรวจสอบสถานะ`
- ทดสอบการค้นหาและกรองรายการผู้ใช้ และยืนยันการปรับขนาดหน้าจอไม่มี scrollbar

## การแจ้งทีมที่เกี่ยวข้อง
- มีการแยกหน้า License ออกจากส่วนแชทอย่างชัดเจนแล้ว
- เพิ่มฟังก์ชันแสดงรายการผู้ใช้งาน/สิทธิ์ พร้อมค้นหา/กรอง
- โปรดอัปเดตคู่มือภายในและกระบวนการซัพพอร์ตให้สอดคล้องกับการเปลี่ยนแปลงนี้

## ข้อควรทราบ
- หาก API `/api/license/users` ไม่มีข้อมูล ระบบจะแสดงตัวอย่าง/ข้อมูลในเครื่องเพื่อการทดสอบ
- การแสดงผลถูกออกแบบให้ย่อ/ขยายให้พอดีกับหน้าจอโดยอัตโนมัติ เพื่อหลีกเลี่ยง scrollbar
